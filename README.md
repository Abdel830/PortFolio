# Portfolio — Abdelali Ouamassi

Portfolio personnel développé avec **React** et **Vite**.

## Démarrage

```bash
npm install
npm run dev
```

Le site sera accessible sur [http://localhost:5173](http://localhost:5173).

## Build production

```bash
npm run build
npm run preview
```

## Structure

- `public/assets/profile.jpeg` — Photo de profil
- `public/assets/CV.pdf` — CV téléchargeable
- `src/data/portfolio.js` — Contenu du portfolio (facile à modifier)

## Sections

- Accueil / Hero
- À propos
- Compétences
- Expériences & projets
- Formation
- Contact
